# Changelog

All notable changes to graphify-openspec-bridge will be documented in this file.

## [1.0.0] — 2026-05-29

### Added

- `graphify-augmented` OpenSpec schema (5 artifacts: proposal, explore, specs, design, tasks)
- CLI tool with `check`, `install`, `validate`, `version`, `help` commands
- `install --with-config` flag for automatic config.yaml setup
- Cross-platform support (macOS, Linux, Windows)
- Comprehensive README with quick start and CLI reference
